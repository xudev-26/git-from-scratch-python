# git-from-scratch-python

About This Project

This is my hands-on learning project for understanding how Git works internally by following the tutorial "ugit: Learn Git Internals by Building Git Yourself" by Leshenko.

Tutorial:
https://www.leshenko.net/p/ugit/

The purpose of this repository is not to simply copy the tutorial's code. The tutorial is my learning guide and reference while I build my own understanding and implementation.

Learning Goals

Through this project, I want to understand:

How Git works internally
How Git stores and represents data
How Git tracks changes
How Git's core mechanisms work underneath the commands I normally use
How these concepts can be implemented in Python
My Learning Process

For each concept, I will:

Study the relevant part of the tutorial.
Understand what the concept is doing and why it is needed.
Implement it myself.
Test and experiment with my implementation.
Make my own changes and variations.
Refactor the code as my understanding improves.
Document important things I learn.

The implementation in this repository may intentionally differ from the tutorial because the goal is to build my own understanding and version rather than reproduce the tutorial exactly.

Project Structure

git/ contains the Python implementation I build throughout the tutorial.

The files will be added progressively as I learn each concept. No complete implementation is provided in advance.

Important Rule

Understand first, implement second.

This repository is primarily a learning exercise. The goal is to understand Git internals deeply enough that I can explain what my code is doing and why it works.
